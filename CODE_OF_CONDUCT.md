# Code of Conduct

Be kind, be curious, and assume good faith. This is a small project about
taking a toy problem seriously; disagreements about the maths are welcome,
personal attacks are not.

Harassment, discrimination, or sustained disruption will result in removal
from the project. Report concerns to the maintainer through a GitHub issue or
direct message.

This is a condensed statement in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
